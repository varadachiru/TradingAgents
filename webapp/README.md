# TradingAgents Research Console (local web UI)

A browser interface for running the same LangGraph research pipeline as the CLI,
using your Codespaces Gemini API key. It runs on your own machine or Codespace;
it is **not** a hosted app or a live broker. Reports are generated by the
existing TradingAgents engine and saved to its normal reports directory.

## Start in GitHub Codespaces

1. Add GOOGLE_API_KEY under **Repository Settings → Secrets and variables →
   Codespaces** (not GitHub Actions). Restart the Codespace after adding it.
   Keep the real key out of files, screenshots and commits.
2. Open the repository terminal and install dependencies:

        python3 -m pip install -e .

3. Start the dashboard:

        python3 -m webapp.server

4. In the Codespaces **PORTS** tab, find port **8765**. Keep visibility
   **Private**, then click **Open in Browser**. If the port is not automatically
   detected, forward port 8765 manually. From a local computer, open
   http://127.0.0.1:8765.

5. Choose a company ticker (e.g. RELIANCE.NS), analysis date, analysts, and
   model tiers. The first recommended test is Market Analyst only with
   Gemini 3.1 Flash-Lite in both model fields and 1 research round.
   Click **Run AI analysis**.

6. Inspect progress and the final portfolio rating. Completed Markdown
   reports remain in ~/.tradingagents/logs/reports/ and appear in
   **Saved analyses** even after the server is restarted.

## How it works

- Backend: Python's standard library HTTP server, bound to 127.0.0.1 by
  default; no extra web-service dependencies.
- Engine: TradingAgentsGraph, with its native streamed updates, checkpoint,
  memory log, and report writer. The website does **not** automate the CLI.
- Provider: Google Gemini via GOOGLE_API_KEY in the Codespaces environment.
  The browser never receives the key.
- Runs: One at a time per web-server process. Concurrent presses are rejected.
  Closing the browser does not stop an ongoing analysis while the server stays
  alive. Stopping the server may interrupt an analysis; checkpoint resume is
  enabled for the same ticker, date, analyst set and settings.
- Report viewer: AI-generated content is returned as plain text, not rendered
  as executable HTML. Other saved CLI reports are also discoverable.
- Request limits: Full analysis starts several analysts concurrently; the
  frontend warns about possible free-tier **429** limits. The web server now
  shares a conservative **6-request/minute** in-process limiter across the
  Gemini model tiers. API-side retries, other processes, or other projects
  can still trigger Google quotas. Start with a small run and monitor usage.

## Important security notes

The web server has no built-in user authentication and is intended **only**
for localhost and your **Private** Codespaces forward. **Never make its port
public or deploy it as an internet-facing service** until authentication,
authorization, cost limits, and provider throttling are added. Anyone who can
access the private server can initiate chargeable Gemini runs and read its
saved reports.

The API accepts only known Gemini models, validated tickers and analyst types,
and cannot execute shell commands or accept user-supplied output file paths.

For development:

    python3 -m pip install -e '.[dev]'
    pytest -q tests/test_web_dashboard.py

No real investment orders or live broker connections are made.
